Sobre este proyecto

Que es este sitio

Este sitio web fue desarrollado como proyecto programado del curso ISW-512 Diseno de Aplicaciones Web de la carrera Ingenieria del Software de la Universidad Tecnica Nacional, bajo la guia del profesor Mit. Sergio Gonzalez Salazar.

El objetivo del proyecto era construir y publicar un sitio real que resolviera una necesidad concreta de un emprendimiento. Glow Up es un negocio de skin care y hair care que hasta ahora vendia unicamente por redes sociales y no contaba con presencia web propia.

Como esta construido

El sitio se desarrollo desde cero, sin partir de ninguna plantilla comercial. Todo el maquetado utiliza Bootstrap 5 bajo la modalidad Mobile First: los estilos base estan pensados para pantallas pequenas y las consultas de medios amplian el diseno hacia tablet y escritorio.

El catalogo de productos, la galeria de imagenes y los pasos de la rutina no estan escritos dentro del HTML. Se publican como archivos JSON dentro del mismo sitio y se consumen como un API Rest mediante jQuery, de forma que el contenido se carga de manera dinamica y actualizarlo no requiere tocar el codigo de las paginas.

El sitio tambien consume un API Rest externo: OpenWeatherMap. En la pagina de inicio se consulta el clima actual y, segun la temperatura y la humedad, se sugiere que tipo de textura y cuidado conviene ese dia. La pagina de ubicacion utiliza la API de Google Maps junto con la geolocalizacion del navegador para mostrar el punto de entrega y trazar la ruta.
