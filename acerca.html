El punto de partida

Por qué existe este sitio

Glow Up vendía únicamente por redes sociales. Los productos estaban repartidos entre publicaciones de Instagram y el catálogo de WhatsApp, y cada consulta de precio se respondía a mano por mensaje directo. Funcionaba, pero no escalaba.

Este sitio resuelve eso: un lugar donde ver todo el catálogo con precios, entender qué producto sirve para qué, y pasar al WhatsApp del negocio con la consulta ya lista. No reemplaza las redes, las complementa.

Cómo está construido

El sitio se desarrolló desde cero, sin partir de ninguna plantilla. Todo el maquetado usa Bootstrap 5 bajo la modalidad Mobile First: los estilos base están pensados para pantallas pequeñas y se amplían hacia tablet y escritorio, no al revés. La mayoría de las visitas llegan desde el celular, así que tiene sentido diseñar para ahí primero.

El catálogo de productos, la galería de imágenes y los pasos de la rutina no están escritos dentro del HTML. Viven en archivos JSON que el sitio consume como un API REST, de forma que el contenido se carga de manera dinámica. La ventaja práctica es concreta: cambiar un precio o agregar un producto se hace editando un archivo de datos, sin tocar el código de ninguna página.

La página de inicio consulta el clima en tiempo real y, según la temperatura y la humedad del día, sugiere qué tipo de textura conviene usar. En un país con clima tropical eso no es un adorno: cambia de verdad lo que le sirve a la piel. La página de ubicación usa el mapa y la geolocalización del navegador para trazar la ruta hasta el punto de entrega, con opción de carro, a pie o autobús.
