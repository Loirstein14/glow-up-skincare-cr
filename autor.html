Sobre mi

Soy estudiante de Ingenieria del Software en la Universidad Tecnica Nacional y me desempeno en el area de automatizacion de procesos (RPA) e inteligencia artificial aplicada. Me interesa especialmente el punto donde se cruzan la automatizacion y el desarrollo web.

Este proyecto lo desarrolle para un emprendimiento familiar que vendia unicamente por redes sociales. Mas alla de cumplir con los requerimientos del curso, el objetivo fue entregar un sitio que el negocio pueda usar de verdad: catalogo actualizable sin tocar codigo, contacto directo por WhatsApp y una base sobre la cual crecer.

Aspectos tecnicos destacados

  • Maquetado responsivo con Bootstrap 5 bajo modalidad Mobile First
  • Catalogo, galeria y rutina servidos como archivos JSON y consumidos como API Rest con jQuery
  • Consumo de API Rest externo (OpenWeatherMap) con logica propia de recomendacion segun el clima
  • Geolocalizacion y trazado de rutas con Google Maps API
  • Validaciones de formulario escritas en JavaScript propio, incluido el calculo automatico de la edad

Codigo fuente disponible en github.com/Loirstein14/glow-up-skincare-cr
