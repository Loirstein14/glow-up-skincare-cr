Este proyecto

Glow Up

01

El reto

Un negocio de skin care y hair care que vendía únicamente por redes sociales. Sin catálogo propio, respondiendo precios uno por uno por mensaje directo.

02

La solución

Un sitio de nueve páginas con catálogo, guía de rutina, galería multimedia y contacto directo por WhatsApp. El contenido se sirve desde archivos JSON, así que actualizar precios no requiere tocar código.

03

El resultado

Presencia web propia que no compite con sus redes sino que las alimenta: cada producto enlaza al WhatsApp del negocio con el mensaje ya listo.

Decisiones técnicas

  • Mobile First. Los estilos base están pensados para móvil y se amplían hacia escritorio, no al revés.
  • Contenido desacoplado. Catálogo, galería y rutina viven en archivos JSON consumidos como API REST.
  • API externa con lógica propia. El sitio consulta el clima y recomienda tipo de textura según humedad y temperatura, algo que importa de verdad en clima tropical.
  • Geolocalización. Mapa con trazado de ruta hasta el punto de entrega, con opción de carro, a pie o autobús.
  • Sin plantillas. Maquetado, hoja de estilos y JavaScript escritos desde cero.
